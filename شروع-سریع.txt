■ روش ۱: استفاده از فایل start.bat (ساده‌ترین)
───────────────────────────────────────
فقط روی فایل start.bat دوبار کلیک کنید!
این فایل همه کارها را خودکار انجام می‌دهد.


■ روش ۲: استفاده از دستورات دستی
───────────────────────────────────────
۱. باز کردن PowerShell یا CMD در پوشه پروژه

۲. نصب وابستگی‌ها:
   python -m pip install -r requirements.txt

۳. ساخت migration ها:
   python manage.py makemigrations

۴. اعمال migration ها:
   python manage.py migrate

۵. ساخت کاربر ادمین:
   python manage.py createsuperuser
   (نام کاربری، ایمیل و رمز را وارد کنید)

۶. ایجاد داده‌های نمونه (اختیاری):
   python manage.py create_sample_data

۷. اجرای سرور:
   python manage.py runserver


■ بعد از راه‌اندازی
───────────────────────────────────────
✅ سایت اصلی: http://127.0.0.1:8000
✅ پنل ادمین: http://127.0.0.1:8000/admin

برای متوقف کردن سرور: Ctrl + C


■ استفاده از پنل ادمین
───────────────────────────────────────
۱. وارد /admin شوید
۲. با کاربر ادمین که ساختید وارد شوید
۳. می‌توانید:
   - دسته‌بندی‌ها را اضافه کنید
   - پرامت‌های جدید بسازید
   - تگ‌ها را مدیریت کنید
   - مجموعه‌ها را ایجاد کنید


■ نکات مهم
───────────────────────────────────────
⚠️  اگر خطای "python not found" گرفتید:
   - مطمئن شوید Python نصب است
   - ممکن است نیاز باشد از py استفاده کنید:
     py manage.py runserver

⚠️  اگر خطای port گرفتید:
   - پورت 8000 در حال استفاده است
   - از پورت دیگری استفاده کنید:
     python manage.py runserver 8080
