  راهنمای نصب و راه‌اندازی Poogo با Django
═══════════════════════════════════════════════════════════

■ مرحله ۱: نصب Python و Django
───────────────────────────────────────
۱. مطمئن شوید Python 3.8+ نصب است:
   python --version

۲. نصب Django و وابستگی‌ها:
   pip install -r requirements.txt

   یا اگر pip ندارید:
   python -m pip install -r requirements.txt


■ مرحله ۲: ساخت دیتابیس
───────────────────────────────────────
۱. ساخت migration ها:
   python manage.py makemigrations

۲. اعمال migration ها:
   python manage.py migrate


■ مرحله ۳: ساخت کاربر ادمین
───────────────────────────────────────
python manage.py createsuperuser

   نام کاربری، ایمیل و رمز را وارد کنید.


■ مرحله ۴: ایجاد داده‌های نمونه (اختیاری)
───────────────────────────────────────
python manage.py create_sample_data

   این دستور چند دسته‌بندی، تگ و پرامت نمونه می‌سازد.


■ مرحله ۵: اجرای سرور
───────────────────────────────────────
python manage.py runserver

   سایت در آدرس زیر در دسترس است:
   http://127.0.0.1:8000

   پنل ادمین:
   http://127.0.0.1:8000/admin


■ استفاده از پنل ادمین
───────────────────────────────────────
۱. وارد /admin شوید
۲. با کاربر ادمین که ساختید وارد شوید
۳. می‌توانید:
   - دسته‌بندی‌ها را اضافه کنید
   - پرامت‌های جدید بسازید
   - تگ‌ها را مدیریت کنید
   - مجموعه‌ها را ایجاد کنید
   - آمار را ببینید


■ ویژگی‌های پنل ادمین
───────────────────────────────────────
✅ فیلتر پیشرفته بر اساس دسته، تگ، سطح، زبان
✅ جستجو در عنوان و محتوا
✅ عملیات دسته‌ای (انتشار، حذف، کپی)
✅ نمایش آمار (بازدید، لایک، کپی)
✅ مدیریت کامل دسته‌بندی‌ها و زیردسته‌ها
✅ اضافه کردن مثال برای هر پرامت


■ نکات مهم
───────────────────────────────────────
- فایل db.sqlite3 دیتابیس شماست (نباید حذف شود)
- فایل‌های استاتیک در پوشه static/ هستند
- برای تغییر تنظیمات، فایل poogo_project/settings.py را ویرایش کنید


■ انتشار روی سرور
───────────────────────────────────────
۱. در settings.py:
   DEBUG = False
   ALLOWED_HOSTS = ['your-domain.com']

۲. جمع‌آوری فایل‌های استاتیک:
   python manage.py collectstatic

۳. استفاده از Gunicorn یا uWSGI برای production
