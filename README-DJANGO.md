# Poogo - پلتفرم پیشرفته پرامت‌ها

سایت پیشرفته برای مدیریت و نمایش پرامت‌های آماده با Django

## ویژگی‌ها

✨ **پنل ادمین فوق پیشرفته**
- فیلتر و جستجوی پیشرفته
- عملیات دسته‌ای (bulk actions)
- آمار و گزارش‌گیری
- مدیریت کامل دسته‌بندی‌ها و تگ‌ها

📚 **بخش آموزش برنامه‌نویسی**
- دسته‌بندی بر اساس سطح (مبتدی، متوسط، پیشرفته)
- مجموعه‌های آموزشی
- مثال‌های کاربردی

🎨 **طراحی مدرن و زیبا**
- طراحی در سطح اینستاگرام
- ریسپانسیو کامل
- انیمیشن‌های نرم

## نصب و راه‌اندازی

### 1. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### 2. ساخت دیتابیس

```bash
python manage.py makemigrations
python manage.py migrate
```

### 3. ساخت کاربر ادمین

```bash
python manage.py createsuperuser
```

### 4. بارگذاری داده‌های نمونه (اختیاری)

```bash
python manage.py loaddata sample_data.json
```

### 5. اجرای سرور

```bash
python manage.py runserver
```

سایت در آدرس `http://127.0.0.1:8000` در دسترس است.

پنل ادمین: `http://127.0.0.1:8000/admin`

## ساختار پروژه

```
poogo/
├── poogo_project/      # تنظیمات اصلی Django
├── prompts/            # اپلیکیشن پرامت‌ها
│   ├── models.py      # مدل‌های دیتابیس
│   ├── admin.py       # پنل ادمین پیشرفته
│   ├── views.py       # View ها
│   └── urls.py        # URL ها
├── templates/          # قالب‌های HTML
├── static/            # فایل‌های استاتیک (CSS, JS)
└── manage.py          # فایل مدیریت Django
```

## استفاده از پنل ادمین

1. وارد `/admin` شوید
2. با کاربر ادمین که ساختید وارد شوید
3. می‌توانید:
   - دسته‌بندی‌ها را اضافه/ویرایش کنید
   - پرامت‌های جدید اضافه کنید
   - تگ‌ها را مدیریت کنید
   - مجموعه‌ها را بسازید
   - آمار را مشاهده کنید

## دسته‌بندی‌های پیشنهادی

- **نویسندگی**: مقاله، داستان، ایمیل
- **برنامه‌نویسی**: کد، باگ، توضیح
- **ساخت عکس**: طراحی، ویرایش، تمپلیت
- **کسب‌وکار**: بازاریابی، فروش، استراتژی
- **آموزش**: توضیح، سوال، تمرین
- **ترجمه**: ترجمه، بازنویسی

## انتشار

برای انتشار روی سرور:

1. تنظیمات `DEBUG = False` در `settings.py`
2. تنظیم `ALLOWED_HOSTS`
3. جمع‌آوری فایل‌های استاتیک: `python manage.py collectstatic`
4. استفاده از یک سرور مثل Gunicorn + Nginx
